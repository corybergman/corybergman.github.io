Over the years, I've published on just about every blog platform known to mankind. When I first launched Lost Remote, blog platforms didn't exist.

Similarly, this new personal blog lacks a CMS, and I'm updating it directly from Claude Code (mostly from my phone). It did a great job porting over my old Tumblr posts, matching the URLs to preserve them in search. I'm hosting on GitHub with Astro on the front end.

While AI is handling the code and polish, the words and photos are still mine. Now let's see if I can keep this updated.
